How does my app use it?

Your app sends its users' transactions with the station as the payer and the user as the payee. Users sign as usual and pay nothing. With Koilib:

{ payer: STATION, payee: user, rcLimit: "19000000" }

If the station says no (for example a user hit the per-minute limit), fall back to the user's own Mana. A refused attempt costs nothing.
